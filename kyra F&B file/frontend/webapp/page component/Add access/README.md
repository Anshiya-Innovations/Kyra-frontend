# KYRA Enterprise Add Access Request Wizard Component

Self-contained SAP Fiori 3-step Access Request Wizard component package.

## Component Features
1. **Step 1: Business Sector & Business Function**: Rectangle form cards with dynamic business function alignment.
2. **Step 2: Region, Systems, Services, Team & Persona**: Multi-Select MultiComboBox controls for systems, services, team roles, and personas.
3. **Step 3: Access Request Summary & Review**: Separated detail cards with final submission action buttons.
