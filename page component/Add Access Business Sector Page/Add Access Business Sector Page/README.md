# KYRA Enterprise Add Access Business Sector Page Component

Dedicated Step-by-Step Business Sector Access Wizard.

## Page Workflow
1. **Step 1**: Select **Business Sector** and dynamic **Business Function** inside clean rectangle cards. Below Step 1 is a prominent **Next Step** button.
2. **Step 2 (Same Page Slide Transition)**: Pop/Slide transition on the same page showing **Region**, **Systems (MultiComboBox multiple selection method)**, **Platform Team**, **Category & Roles**, and **Business Justification**.
